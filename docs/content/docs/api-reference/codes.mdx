Codes are stable identifiers, never list positions. The tables below describe the current source contract. Names are display values; use codes for supported numeric filters. There is no reference-data endpoint.

## Evolving code tables

Do not infer future codes, renumber existing values or assume alphabetical ordering. If your application bundles these tables, update them with contract changes or request expansion for display labels. The docs test suite compares the source product, brand and region maps and controlled feature/restriction labels with this snapshot.
