The FuelWatch API makes published Western Australian fuel prices easier to use in applications, automations and Home Assistant integrations. It is an independent project maintained by [Bradley Hodges](https://github.com/bradleyhodges), using price data from [FuelWatch WA](https://www.fuelwatch.wa.gov.au).

Each `serviceStation` resource combines a station's selected fuel prices with normalized address, contact and facility information. The API uses JSON:API 1.1 response documents, compact reference codes and explicit AWST price periods.

## What to expect

Published source snapshots are cached for up to six hours and refreshed hourly for the unfiltered product catalogue. Response lifetimes can be shorter at time boundaries. Cached responses may outlive an hourly refresh; read the [caching guide](/docs/caching) before choosing a polling strategy.

Optional Google Maps enrichment fills some missing station details. It never changes FuelWatch prices or source identity, and can be absent. Keep [attribution](/docs/enrichment) with enriched information.

<Note>
This site documents the current Worker source contract. A deployed version may lag behind it. The service is independent of the WA Government; the upstream price publisher is identified by `meta.source`.
</Note>

The API is read-only. It has no login, mutations, station detail route, pagination, server-side sort or separate reference-data endpoint. Examples use ordinary HTTP clients; no SDK is required.
